# R.A.12_Minimisation

## Installation

### Prérequis

- Python 3.14.7

### Créer l'environnement virtuel

Sur pycharm, il est normalement créer (dossier .venv dans le projet)

Sinon:
```bash
python -m venv .venv
```

### Activer l'environnement virtuel

Sur pycharm, il est par défault activer (dans un terminal, (.venv))

Sinon:
```bash
.\venv\Scripts\activate
```

### Installer les dépendances

```bash
pip install -r requirements.txt
```

### Lancement du projet

Le backend de jupyter notebook de pycharm ne fonctionne pas très bien avec les animations, pour lancer le projet, exécutez cette commande:

```bash
jupyter lab
```
